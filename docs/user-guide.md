# 使用手册

> 发送端、接收端控制台、记分牌、沉浸预览的完整操作说明。

---

## 1. 首页与模式选择

打开 App 是模式选择页，两张卡片分别进入：

- **发送端**：第一台（采集 / 推流 / 录制）。
- **接收端**：第二台（监看 / 记分 / 计时）。

右上角 **「关于我们」** 可查看作者、开源说明与 GNU GPLv3 许可协议。

---

## 2. 发送端

发送端为左右两栏布局：左栏是采集参数与推流目标，右栏是运行状态与本地录制。

### 2.1 采集参数（下次开始采集生效）

| 项 | 可选值 |
| --- | --- |
| 画面高度 | `720p` / `1080p` |
| 帧率 | `30 fps` / `60 fps` |
| 码率上限 | `4 / 6 / 8 Mbps` |

> 码率通过改写 SDP 的 `b=AS` / `b=TIAS` 行实现，不依赖 WebRTC 具体版本内部 API。

### 2.2 推流目标

- **扫码连接**：打开相机扫描接收端二维码，自动解析出 `IP:端口`。
- **手动连接**：直接输入 `192.168.x.x:8770`。

连接建立后会显示信令状态、ICE 状态、Peer 状态。

### 2.3 屏幕采集与推流

1. **开始屏幕采集**：触发系统投屏授权，允许后进入 `mediaProjection` 前台服务。
2. **开始推流**：开始向接收端推送画面。

> 采集由前台服务承载，切后台、锁屏不会中断；通知栏会常驻一条通知。

### 2.4 本地录制

- **开始录制到 MP4 / 停止录制**：复用 WebRTC 编码前的视频帧，输出 H.264 MP4。
- 面板显示**已编码帧**数与保存位置。
- 与推流画面完全一致，**不需要二次投屏授权**。
- 文件位置：`Android/data/com.matchconsole/files/Movies/`。

### 2.5 运行状态

显示采集状态、信令 / ICE / Peer 状态、接收端地址、分辨率、帧率、码率、RTT、丢包，便于判断链路质量。

## 3. 接收端 · 赛事控制台

接收端为横屏四区域布局：

```
┌──────────────────────────────┬───────────────┐
│                              │  比分控制区    │
│         主 画 面 区           │               │
│                              ├───────────────┤
│  （16:9 等比适配，可沉浸）      │  计时控制区    │
├──────────────────────────────┤               │
│      记 分 牌 横 条（可开关）    ├───────────────┤
│                              │  状态与设置区  │
└──────────────────────────────┴───────────────┘
```

记分牌横条位于**推流画面下方**，是独立的一条，**不会遮挡画面**。

### 3.1 主画面区

- 画面按 16:9 **等比适配**，完整可见（可能留黑边）；也可切换为**裁切**铺满。
- 左上角显示链路指标（ICE / Peer 状态、分辨率 · 帧率 · 码率、延迟 · 丢包），可整体关闭。
- 右上角快捷开关：
  - **指标**：显示 / 隐藏画面上的链路指标浮层。
  - **纯净画面**：一键屏蔽**所有**盖在画面上的东西（记分牌、指标、连接角标、快捷条），
    只保留角上一个很小的「显示浮层」按钮用于恢复。
  - **沉浸预览 / 退出沉浸**：见 [3.5](#35-沉浸预览)。

### 3.2 比分控制区

| 操作 | 说明 |
| --- | --- |
| 点击队名 | 弹出输入框改名（主队 / 客队） |
| `+1 / +2 / +3` | 对应队加分 |
| `-1` | 对应队减分 |
| `− / +`（犯规） | 调整该队犯规数 |
| `− / +`（暂停） | 调整该队暂停数 |
| `◀ 上 / 下 ▶` | 切换节次 |

比分变化会立即同步到记分牌，并带高亮反馈。

### 3.3 计时控制区

- **比赛时间**：大字号显示，`开始 / 暂停` 与 `重置`。
- **进攻时限**：`24 秒 / 14 秒` 快捷设置，以及开关（开 / 关进攻时限）与限时启动。
- **补时 / 扣时**：`+1′ / -1′`。
- **暂停计时**：独立倒计时，`开始 / 重置`。

### 3.4 状态与设置区

- 连接状态、ICE / Peer、发送端地址、本机 `IP:端口`。
- **二维码**：未连接时显示，供发送端扫码。
- 画面分辨率 / 帧率、码率 / 编码、延迟 / 抖动、累计丢包。
- 开关项：
  - **记分牌：显示 / 隐藏**（控制画面下方的记分牌横条）。
  - **快捷记分条：开 / 关**（沉浸模式下底部快捷条）。
  - **画面指标：显示 / 隐藏**。
  - **纯净画面：开 / 关**。
  - **画面：适配 / 裁切**。
  - **主题：浅色 / 深色**。
  - **录制接收画面**：接收端本地录制（复用收到的视频帧）。
- **一键重置比赛 / 清空全部**。

### 3.5 沉浸预览

点主画面右上角 **「沉浸预览」**：

- 主画面铺满整屏，顶部标题栏隐藏，纵向空间全部让给画面。
- 画面**顶部叠加**一条半透明记分牌（不占用画面外的空间）。
- 底部出现**半透明快捷记分条**：两队 `+1 / +2 / +3 / -1`，中间是开始 / 暂停 / 重置。
- 右上角出现 **「记分条开 / 关」**：关掉后底部快捷条消失，**画面上零遮挡**，只剩推流画面。
- 点 **「退出沉浸」** 回到四区域控制台。

### 3.6 数据持久化

比分、队名、节次、犯规、暂停、计时设置、主题、各开关状态都会通过 DataStore 保存，
**App 重启后自动恢复上一场**。

---

## 4. 快捷记分条对照

| 位置 | 按钮 | 作用 |
| --- | --- | --- |
| 左 / 右两侧 | `+1` `+2` `+3` `-1` | 主队 / 客队加减分 |
| 中间 | `▶ / ⏸` | 开始 / 暂停比赛计时 |
| 中间 | `重置` | 重置比赛计时 |
